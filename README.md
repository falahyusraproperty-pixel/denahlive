# DenahLive Landing Page

Landing page statis berbahasa Indonesia, dibuat tanpa framework atau build step dan siap dipublikasikan melalui GitHub Pages.

## Publikasi
Workflow `.github/workflows/pages.yml` akan berjalan otomatis saat ada perubahan pada branch `main`.

URL target: https://falahyusraproperty-pixel.github.io/denahlive/

Jika workflow gagal karena GitHub Pages belum diaktifkan, buka **Settings → Pages**, pilih **GitHub Actions** sebagai Build and deployment source, lalu jalankan ulang workflow pada tab Actions.

## Sebelum promosi
- Verifikasi nomor WhatsApp pada CTA di `index.html`.
- Pratinjau siteplan, jumlah unit, dan checklist dokumen adalah **ilustrasi UI**, bukan data proyek nyata.
- DenahLive membantu pencatatan dan pemantauan dokumen; halaman ini tidak menyatakan atau menjamin kepatuhan hukum suatu proyek.
- Konfirmasi bahwa deskripsi fitur sesuai dengan versi produk yang tersedia saat ini.

## Teknologi
HTML, CSS, dan JavaScript dalam satu file. Tidak ada database atau form lead server-side; CTA membuka WhatsApp.
